# Kaggle issues encountered

1. **`train.py` not found on Kaggle** — `%run train.py` failed: Kaggle doesn't ship the file.
   Fix: embed train.py's full source directly into the notebook (generated by `_gen_notebook.py`).
2. **PyTorch incompatible with P100 (sm_60)** — default Kaggle torch (2.5+/2.10) can't run on P100.
   Fix: notebook installs `torch==2.4.0 torchvision==0.19.0 --index-url .../cu121` + assert cell.
3. **OOM during training** — logits `8×1024×100277×4 ≈ 3.06 GiB` fp32; cross_entropy upcasts despite
   autocast. Fix: batch 8→2, grad_accum 1→8, eval under autocast, `empty_cache()` before eval.
4. **`NameError: __file__` in embedded cell** — notebook kernels don't define `__file__`.
   Fix: `_BASE_DIR = Path(__file__).resolve().parent if "__file__" in globals() else Path.cwd()`.
5. **`SystemExit: 2` from argparse** — `main()`'s `parse_args()` consumed the kernel launcher's args
   (`-f /tmp/... --HistoryManager.hist_file=:memory:`). Fix: `parse_args([])` when `__file__` absent.
6. **Stale notebook deployed** — offline runs used old layouts; re-upload HEAD `train_notebook.ipynb`
   after every regeneration.
7. **Auto-start via `__name__` guard** — notebook runs with `__name__ == "__main__"`, so the guard
   would auto-run training. Fix: strip the guard in the embedded cell; call `main()` explicitly in
   its own final cell.
8. **Multiple datasets under `/kaggle/input`** — corpus + openwebtext mounted; no hardcoded slugs.
   `_detect_input_dir()` / `_append_openwebtext()` auto-glob `/kaggle/input`.
9. **`/kaggle/working` wiped each run (OPEN)** — cache_dir resets, causing re-tokenization of the
   custom corpus each run. Persist gpt2 `data.bin` as a dataset to solve (OWT is pretokenized).
10. **rich `RecursionError` (OPEN)** — `Monitor` uses `Console()` + `Live()` (train.py:460-461); rich's
    `is_terminal` check recurses under papermill/non-TTY output. Likely fix: `Console(force_terminal=False)`.
